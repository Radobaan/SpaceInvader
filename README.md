# Space Invader

A 2D Space Invader-style game developed using Godot Engine.

## Version
v1.0.0

## Features
- Player movement
- Automatic shooting
- Enemy spawning
- Enemy HP and damage system
- Player lives system
- Game Over screen
- Score system

## Controls
- W / A / S / D : Move player

## Built With
- Godot Engine 4.7.2
- GDScript

## How to Run
1. Clone this repository.
2. Open Godot Engine.
3. Import project.godot.
4. Run Main scene.
